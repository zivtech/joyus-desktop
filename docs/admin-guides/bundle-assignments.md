# Bundle Assignment Guide

**Date**: 2026-03-10
**Audience**: Cowork workspace administrators (Zivtech, Milk Jawn)

## Overview

Skills are organized into role-based bundles. Each bundle is a plugin set assigned to users via the Cowork admin panel. Users receive only the skills in their assigned bundle.

## How to Assign Bundles

### Step 1: Access Cowork Admin Panel

1. Log in to [claude.ai](https://claude.ai) with an admin account
2. Navigate to **Settings** → **Workspace** → **Plugins** (or **Connectors**)
3. You should see the plugin management interface

### Step 2: Upload Plugin Sets

For each bundle:
1. Click **Add Plugin** or **Import Plugin Set**
2. Upload the plugin files from the `plugins/` directory (generated by `scripts/build-cowork-plugins.ts`)
3. Set the bundle name and description from `config/bundles/*.json`
4. Verify the skill list matches the bundle manifest

### Step 3: Assign to Users

1. Navigate to **Workspace Members** or **User Management**
2. For each user, select their role-appropriate bundle
3. Confirm assignment

### Step 4: Verify

1. Log in as a non-admin user with an assigned bundle
2. Check that skills appear in available commands
3. Invoke one skill to verify execution
4. See `docs/verification/wp01-smoke-test.md` for the full verification checklist

## Updating Skills

When a new version is released (version pin changed via WP04):

1. Run `scripts/build-cowork-plugins.ts` against the new tag
2. Upload updated plugin files to Cowork
3. Users receive updates on their next session

## Overlap Handling

Users belonging to both Zivtech and Milk Jawn (dual-org) should be assigned:
- The **Full Bundle** in their primary org
- No bundle in their secondary org (to avoid duplicates)

If Cowork shows duplicate skills, remove the bundle from the secondary org.
