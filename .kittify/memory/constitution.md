## Purpose

This constitution captures the technical standards for joyus-desktop. All
features and pull requests should align with these principles.

## Technical Standards

### Languages and Frameworks
- TypeScript 5.8+ with strict mode (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`)
- Node.js 24, ESM-only (`"type": "module"`)
- pnpm 10.5 workspaces (monorepo: `apps/*`, `packages/*`)
- Vitest for testing, tus-js-client for resumable uploads
- Target: ES2022

### Testing Requirements
- Vitest with v8 coverage provider
- **100% coverage** threshold on lines, functions, branches, and statements
- Tests located in `{package}/test/*.test.ts`
- CI blocks merges if typecheck or coverage fails

### Performance and Scale
- Optimize for speed — minimize latency for end users
- Prefer enabling features to run locally within the Claude Code or Cowork session rather than round-tripping to remote services
- Scale is not a primary concern; user-perceived responsiveness is

### Deployment and Constraints
- Desktop application targeting **macOS** and **Windows**
- Distributed directly to user machines

## Governance

### Amendment Process
Any team member can propose amendments via pull request. Changes are discussed
and merged following standard PR review process.

### Compliance Validation
Code reviewers validate compliance during PR review. Constitution violations
should be flagged and addressed before merge.

### Exception Handling
Exceptions discussed case-by-case with team. Strong justification required.
Consider updating constitution if exceptions become common.
