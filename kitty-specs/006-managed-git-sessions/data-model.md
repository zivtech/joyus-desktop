# Data Model: Managed Git Sessions

**Feature**: 006-managed-git-sessions
**Date**: 2026-03-19

---

## Entities

### TaskBranch

The core persistent record. One per session per git repository (in managed mode). Stored in `~/.joyus/session-manager.db`.

| Field | Type | Nullable | Description |
|---|---|---|---|
| `id` | `string` (UUID v4) | No | Primary key |
| `session_id` | `string` | No | Claude Code session ID (from IPC or generated); unique per active session |
| `repo_path` | `string` | No | Absolute path to the git repository root |
| `worktree_path` | `string` | No | Absolute path to the git worktree directory |
| `branch_name` | `string` | No | Underlying git branch name (e.g., `joyus/2026-03-19-update-homepage`) |
| `mission_label` | `string` | No | Human-readable label; user-declared or auto-inferred |
| `mission_source` | `"declared" \| "inferred"` | No | Whether the label was provided by the user or auto-generated |
| `mode` | `"managed" \| "advisory"` | No | Operating mode at time of creation; does not change after creation |
| `status` | `"active" \| "stale" \| "merged" \| "broken"` | No | Current lifecycle state |
| `created_at` | `number` (Unix ms) | No | Creation timestamp |
| `last_activity_at` | `number` (Unix ms) | No | Timestamp of most recent file modification event |
| `deleted_at` | `number` (Unix ms) | Yes | Soft-delete timestamp; null if not deleted |

**Indexes**: `session_id` (unique, partial where `deleted_at IS NULL`), `repo_path`, `status`, `last_activity_at`.

**State machine**:

```
active ──(no activity > threshold)──────────────────→ stale
active ──(underlying branch merged into default)──→ merged
active ──(worktree missing on disk)────────────────→ broken
stale  ──(user resumes)────────────────────────────→ active
stale  ──(underlying branch merged into default)──→ merged
stale  ──(worktree missing on disk)────────────────→ broken
merged ──(user deletes)────────────────────────────→ [soft-deleted]
broken ──(user cleans up)──────────────────────────→ [soft-deleted]
any    ──(user deletes)────────────────────────────→ [soft-deleted]
```

**Branch naming convention**: `joyus/<YYYY-MM-DD>-<mission-slug>` where `mission-slug` is the mission label lowercased and hyphenated. Collisions resolved by appending `-2`, `-3`, etc.

### DriftSignal (in-memory, not persisted)

Generated by `packages/drift-detector` and emitted to the sidecar event bus. Not stored in SQLite.

| Field | Type | Description |
|---|---|---|
| `task_branch_id` | `string` | The `TaskBranch.id` this signal relates to |
| `confidence` | `"low" \| "high"` | Low = single threshold exceeded; High = two or more thresholds exceeded |
| `signals` | `DriftHeuristicResult` | The three heuristic values that produced this signal |
| `explanation` | `string \| null` | LLM-generated plain-language explanation (null in v1) |
| `generated_at` | `number` (Unix ms) | When the signal was generated |

---

### DriftHeuristicResult (embedded in DriftSignal)

| Field | Type | Description |
|---|---|---|
| `directory_count` | `number` | Distinct top-level directories touched in this session |
| `directory_threshold` | `number` | Configured threshold (default: 3) |
| `directory_exceeded` | `boolean` | Whether directory_count ≥ directory_threshold |
| `topic_domain_count` | `number` | Distinct inferred topic domains |
| `topic_domain_threshold` | `number` | Configured threshold (default: 2) |
| `topic_domain_exceeded` | `boolean` | Whether topic_domain_count ≥ topic_domain_threshold |
| `elapsed_minutes` | `number` | Minutes since session start |
| `elapsed_threshold_minutes` | `number` | Configured threshold (default: 30) |
| `elapsed_exceeded` | `boolean` | Whether elapsed_minutes ≥ elapsed_threshold_minutes |

---

### DriftDismissal (in-memory, session-scoped)

Tracks declined drift suggestions so the same signal is not re-surfaced. Cleared on session end. Not persisted.

| Field | Type | Description |
|---|---|---|
| `task_branch_id` | `string` | The session's `TaskBranch.id` |
| `dismissed_at` | `number` (Unix ms) | When the user dismissed the signal |
| `signal_fingerprint` | `string` | Hash of `DriftHeuristicResult` at dismissal time |

---

### DriftThresholds (settings, persisted in app config)

| Field | Type | Default | Description |
|---|---|---|---|
| `directory_count` | `number` | `3` | Min distinct top-level directories to trigger low-confidence |
| `topic_domain_count` | `number` | `2` | Min distinct topic domains to trigger low-confidence |
| `elapsed_minutes` | `number` | `30` | Min session duration (minutes) to trigger low-confidence |
| `stale_days` | `number` | `14` | Days of inactivity before a `TaskBranch` is flagged stale |

## Topic Domain Inference

Topic domains are inferred from file paths using a keyword-to-domain lookup. The initial mapping:

| Keywords in path | Domain |
|---|---|
| `components`, `ui`, `pages`, `views`, `styles`, `css`, `scss` | `frontend` |
| `api`, `routes`, `controllers`, `handlers`, `middleware`, `server` | `backend` |
| `test`, `spec`, `__tests__`, `fixtures` | `testing` |
| `docs`, `documentation`, `README`, `CHANGELOG` | `documentation` |
| `config`, `settings`, `env`, `.github`, `ci`, `cd` | `configuration` |
| `schema`, `migration`, `db`, `database`, `models` | `data` |
| `scripts`, `bin`, `tools`, `build` | `tooling` |
| `auth`, `security`, `permissions` | `security` |

A file whose path matches none of the above is assigned domain `"other"`. Domain count = number of distinct non-`"other"` domains observed.

## SQLite Schema

```sql
CREATE TABLE task_branches (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,
  repo_path TEXT NOT NULL,
  worktree_path TEXT NOT NULL,
  branch_name TEXT NOT NULL,
  mission_label TEXT NOT NULL,
  mission_source TEXT NOT NULL CHECK (mission_source IN ('declared', 'inferred')),
  mode TEXT NOT NULL CHECK (mode IN ('managed', 'advisory')),
  status TEXT NOT NULL CHECK (status IN ('active', 'stale', 'merged', 'broken')),
  created_at INTEGER NOT NULL,
  last_activity_at INTEGER NOT NULL,
  deleted_at INTEGER
);

CREATE UNIQUE INDEX idx_task_branches_session_id
  ON task_branches (session_id)
  WHERE deleted_at IS NULL;

CREATE INDEX idx_task_branches_repo_path
  ON task_branches (repo_path);

CREATE INDEX idx_task_branches_status
  ON task_branches (status)
  WHERE deleted_at IS NULL;

CREATE INDEX idx_task_branches_last_activity
  ON task_branches (last_activity_at)
  WHERE deleted_at IS NULL;
```
